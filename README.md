## The entry

A one-line family scene: Dad burns the toast, Mum rescues the moment by
rebranding it "smoky artisan style", and six-year-old Leo eats two slices
anyway, crumbs on his chin, grinning like he has just won a prize. Warm and
heartfelt first, with a light funny turn and one specific detail — Leo, six
and loyal to a fault — that makes it this family, not any family.

## How it works

`main.ts` (Node.js standard library only, no dependencies, no network) writes
the scene as UTF-8 plain text to `entry.txt` inside the directory given by
`MAKEFUN_OUTPUT_DIR` (default `/output`). The text is a single line, plain
ASCII, no trailing newline, and well under the 280-character limit.

Run it with:

```sh
node main.ts
```
